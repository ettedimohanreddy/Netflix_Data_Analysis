# Netflix Data Analysis Using Python

## Project Overview

This project was completed as part of a **4-Week Internship on Data Analysis Using Python at Auspify Technologies**.

The main objective of this project is to analyze Netflix content data using Python and its data analysis libraries. It focuses on understanding the distribution of Movies and TV Shows, identifying popular countries and genres, analyzing content ratings, and exploring release-year trends.

The project also includes interactive visualizations and a business insights report to present the findings in an understandable way.

## Internship Tasks

### Task 1: Netflix Data Cleaning and Preparation
- Loaded the Netflix dataset using Pandas.
- Identified and handled missing values.
- Removed duplicate records.
- Standardized columns and inconsistent values.
- Exported the cleaned dataset for further analysis.

### Task 2: Content Type Analysis Dashboard
- Analyzed the distribution of Movies and TV Shows.
- Calculated content counts and percentages.
- Created visualizations to compare content types.
- Summarized the findings.

### Task 3: Country-Wise Netflix Content Analysis
- Extracted individual country names from the dataset.
- Analyzed content availability across countries.
- Identified the top content-producing countries.
- Created country-wise rankings and visualizations.

### Task 4: Trend Analysis by Release Year
- Analyzed Netflix content based on release year.
- Calculated yearly content releases.
- Identified growth and decline trends.
- Created visualizations to understand historical patterns.

### Task 5: Content Rating and Genre Analysis
- Analyzed different content rating categories.
- Identified the most frequently listed genres.
- Compared ratings across Movies and TV Shows.
- Created interactive visualizations.

### Task 6: Netflix Business Insights Report
- Performed Exploratory Data Analysis (EDA).
- Combined key findings from different analysis areas.
- Developed an interactive business insights dashboard.
- Generated actionable insights from the dataset.
- Prepared a final analytical report.

## Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd Netflix_Internship
```

### 3. Install the required libraries

```bash
python -m pip install pandas numpy matplotlib seaborn plotly
```

### 4. Run the tasks

Run Task 1 first because it generates the cleaned dataset used by the remaining tasks.

```bash
python Task_1_Data_Cleaning/Data_Cleaning.py
```

Then execute the remaining tasks:

```bash
python Task_2_Content_Analysis/Content_Analysis.py

python Task_3_Country_Analysis/Country_Analysis.py

python Task_4_Release_Year_Analysis/Release_Year_Analysis.py

python Task_5_Rating_Genre_Analysis/Rating_Genre_Analysis.py

python Task_6_Business_Insights/Business_Insights.py
```

**Note:** Keep `Dataset.csv` in the project root directory before running the scripts. Run Task 1 before Tasks 2–6.
